# ALPVP Android Application

## Prerequisites

Before running the application, make sure the following software is installed:

- Android Studio
- Git
- Java Development Kit (JDK)
- PostgreSQL (required by the backend)

---

## Backend Setup

This Android application depends on the ALPVP Backend API.

1. Clone the backend repository:

```bash
git clone https://github.com/BZBBZBZZ/ALPVPBACKEND.git
```

2. Open the backend project and follow all setup instructions provided in the backend repository README:

https://github.com/BZBBZBZZ/ALPVPBACKEND

3. Ensure the backend server is running successfully before launching the Android application.

---

## Android Application Setup

1. Clone this repository:

```bash
git clone <YOUR_ANDROID_REPOSITORY_URL>
```

2. Open the project in Android Studio.

3. Wait for Gradle Sync to complete.

4. Verify that the API Base URL in the project points to the running backend server.

5. Build and run the application using:
   - Android Emulator, or
   - Physical Android Device

---

## Running the Application

1. Start the backend server.
2. Ensure the database has been migrated and seeded according to the backend setup instructions.
3. Run the Android application from Android Studio.
4. Log in using one of the seeded accounts available in the backend database.
